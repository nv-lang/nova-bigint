# nova-bigint

Целые произвольной точности (`BigInt`) для [Nova](https://github.com/nv-lang/nova) —
**на чистом Nova, без C-зависимостей**.

## Зачем отдельным пакетом

Ядро языка остаётся fixed-width с trap-политикой переполнения (D423): `int`/`i64`
ловят переполнение, а не заворачивают его молча. Произвольная точность нужна не
каждой программе, поэтому она — подключаемая зависимость, а не часть обязательной
поставки `std`. Тот же принцип, что у `nova-tls` и `nova-compress`.

Реализация — чистый `.nv` без GMP/libtommath: bignum это переносимая арифметика,
ровно тот класс кода, который должен жить в Nova, а не в C. Эталон подхода —
Go `math/big` (тоже чистый Go).

## Состояние

**V1 в работе.** Готово ядро (план 235, Ф.1):

- представление: знак (`-1`/`0`/`+1`) + лимбы `[]u32` little-endian без ведущих
  нулей; ноль каноничен (единственное представление);
- конверсии из машинных целых и обратно;
- сложение и вычитание величин с переносом;
- сравнение, равенство, отрицание, модуль.

Ещё нет: умножение и деление (Ф.2), строковые конверсии (Ф.3).

## Использование

```toml
# nova.toml вашего пакета
[dependencies]
bigint = { git = "https://github.com/nv-lang/nova-bigint", version = "0.1" }
```

```nova
import bigint.{BigInt}

ro a = 1000000007.to_bigint()
ro b = a.add(a)
```

Неявных коэрсий `int → BigInt` нет и не будет: аллокация не бывает бесплатной,
поэтому конверсия всегда явная (`to_bigint`).

## Тесты

```sh
nova test src
```

Тесты лежат рядом с модулем (`src/bigint_test.nv`, тот же `module bigint`) —
конвенция Nova «тесты рядом с модулем».
